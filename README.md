# Bloom & Co. Florist

## Project Overview
Bloom & Co. Florist is a fictional Cape Town-based florist website created as part of the WEDE5020 Web Development assignment. The website showcases floral arrangements and provides visitors with information about the business, its services and enquiry options.

## Website Pages
- **Home:** Introduction and featured floral collection.
- **About:** Business background, mission and vision.
- **Services:** Floral arrangements and services offered.
- **Enquiries:** Form for customers to submit flower enquiries.
- **Contact:** Business contact information and operating hours.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git and GitHub

## Features
- Responsive layouts for desktop, tablet and mobile.
- Navigation between five website pages.
- Floral images and service cards.
- Enquiry form.
- Hover and focus effects.
- Search-engine optimisation metadata.

## Project Structure
- `index.html` – Homepage
- `about.html` – About page
- `services.html` – Services page
- `enquiry.html` – Enquiry page
- `contact.html` – Contact page
- `styles.css` – Main stylesheet
- `js/script.js` – JavaScript functionality
- `images/` – Website images
- `screenshots/` – Responsive testing screenshots
- `robots.txt` – Search engine crawling instructions
- `sitemap.xml` – Website sitemap
